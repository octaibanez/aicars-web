# AiCars — web de la agencia

Sitio estático (un solo `index.html` + `assets/`). Sin build: se sube la carpeta tal cual a cualquier hosting/Easypanel y se apunta el dominio con registro A.

## Archivos
- `index.html` — toda la página (CSS y JS adentro).
- `assets/logo-original.png` — logo original con fondo negro.
- `assets/logo-full.png` — logo completo sin fondo (footer).
- `assets/logo-mark.png` / `logo-nav.png` — solo AICARS + auto (barra y marca de agua del footer).
- `assets/favicon.svg` — ícono provisorio.
- `assets/clientes/` — logos de las 11 concesionarias (lista en `CLIENTES` al final del index; si falta un archivo muestra el nombre).
- `assets/media/` — video del hero (Pexels 7154222, licencia libre), fotos `salon.jpg` y `llaves.jpg` (Pexels, Antoni Shkraba).
- `archives/v1-index.html` — primera versión (descartada: muy abstracta). `archives/v2-index.html` — v2 estilo Framer.

v2 (2026-10-13): estructura tomada de olead.framer.ai (video real + celular con mensajes, cinta de logos, odómetros, demo YouTube, 3 pilares, FAQ, CTA con foto).
